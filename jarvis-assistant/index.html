Outlook / Microsoft 365
Requires an Azure AD app registration (free, under your own Microsoft account) — I can't create this for you. In portal.azure.com → App registrations → New registration: set platform type "Single-page application", redirect URI as shown below, and add delegated permissions Mail.Read, Mail.ReadWrite, User.Read. Then paste the Application (client) ID here.
Outlook access is read + draft only — Jarvis can never send an email on its own.
Local hosting (required for Outlook and Work Folder)
